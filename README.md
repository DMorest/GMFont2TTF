# 关于该项目

这个项目可以将用于GameMaker引擎识别的字体文件（png和对应csv）转换为通用的ttf字体文件。文件中不存在的字形会自动使用通用fallback字体补全。
**【注意：fallback字体不包含在本仓库内，需要自行寻找】**

## 使用方法：
1. 确保将fallback字体命名为`fallback.ttf`，并放在`main.py`同目录下。
2. 将需要转换的字体文件（png和对应csv）放置在`main.py`同目录下的`input`文件夹中。（可以嵌套文件夹，脚本会自动读取并按照目录结构输出）
3. 确保安装了`requirements.txt`中的库。
4. 运行`main.py`。
5. 在`output`文件夹找到输出的ttf文件。

# About the project

(This is an English description of the repository. )
This project can be used to convert font file used by GameMaker (png and corresponding csv) to commonly used ttf file. Glyphs not included in the png/csv will automatically use the fallback font. 
**[[Caution: the fallback font is not included in the repository. You need to find one yourself. ]]**

## How to use:
1. Make sure that the fallback font is named `fallback.ttf` and is put under the same directory as `main.py`. 
2. Put the font files that need to be converted under the `input` folder in the same directory as `main.py`. (Nested folders are supported and the directory structure will be preserved in the output.)
3. Make sure the modules in `requirements.txt` are installed. 
4. Run `main.py`
5. Find the ttf files in the `output` folder.

# このプロジェクトについて

このプロジェクトは、GameMaker エンジンが認識するフォントファイル（png と対応する csv）を汎用の ttf フォントファイルに変換することができます。ファイルに含まれない字形は自動的に汎用の fallback フォントで補完されます。
【注意：fallback フォントは本リポジトリに含まれていません。ご自身で用意してください】

## 使用方法：
1. fallback フォントを `fallback.ttf` という名前にし、`main.py` と同じディレクトリに置いてください。
2. 変換したいフォントファイル（png と対応する csv）を `main.py` と同じディレクトリにある `input` フォルダに置いてください。（フォルダはネスト可能で、スクリプトが自動的に読み取り、ディレクトリ構造を維持して出力します）
3. `requirements.txt` にあるライブラリがインストールされていることを確認してください。
4. `main.py` を実行してください。
5. `output` フォルダに出力された ttf ファイルを確認してください。
